Omarchy is a keyboard-first Linux desktop built on Arch and Hyprland by David Heinemeier Hansson (DHH), and its production pipeline, packaging builds, PR review agents, and QA testing, now run on DigitalOcean. Agent workloads don’t behave like a typical web server. They’re bursty and parallel: an agent spins up, does one job, and shuts down.
